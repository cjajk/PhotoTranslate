# PhotoTranslate · 拍照翻译

拍照/选图 → OCR 词框叠加 → 点词完整释义 → 整段翻译 → 查词搜索 → 收藏复习。

## v0.3.0（当前）

- 拍照（系统相机）/ 相册选图，双指缩放跟随质心、可拖动，侧边 ＋/－ 缩放按钮（静止 5 秒自动隐藏）
- OCR 词框叠加（Google ML Kit Text Recognition v2，设备需带 Google Play 服务）
- 点词弹窗：音标（英/美）、词性分组完整义项、词形变化、考纲标签、英英释义（百度 edict + Free Dictionary API）
- 整段翻译：POST 请求 + 长文本分块拼接，结果限高可滚动，失败可重试
- 手动查词页（底部第 5 项）：单词/词组查词典，句子整句翻译，保留最近 20 条搜索历史
- 收藏复习：单词/句子收藏带完整释义摘要
- 历史记录：拍照自动压缩保存（长边 ≤1600、JPEG 质量 80），可回看、可一键清空
- 设置页：百度翻译 / 有道智云，APP ID 与密钥密文掩码 + 眼睛切换，问号教程页
- 进程内翻译缓存（LruCache），同词不重复打 API

## 云构建

推送到 main 分支触发 GitHub Actions，产物在 Actions 或 Release v0.3.0 下载。
